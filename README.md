# E-VIP

Установочные пакеты и обновления инструментов AutoCAD.

Доступен [предварительный выпуск 0.8.0](https://github.com/evipevipevip-cmyk/E-VIP-Releases/releases/tag/v0.8.0-r4): 60 пакетов для AutoCAD 2018 x64, 2024 и 2025. Добавлены бессрочные лицензии и управление сроком, остановкой и возобновлением через подписанный статус GitHub без пересылки нового файла сотруднику.

## Установка и переход на 0.8

Получите у администратора архив с установщиком E-VIP и личной лицензией. Распакуйте архив целиком, сохраните чертежи, закройте AutoCAD и запустите E-VIP_Install.exe. Выберите вашу версию AutoCAD. Установщик проверит подпись каталога и целостность скачиваемых пакетов.

Сначала обновите E-VIP до 0.8 во всех используемых версиях AutoCAD, затем применяйте новые статусы лицензий. Прежние клиенты не понимают новую схему доступа. При обновлении существующего сотрудника его основной файл лицензии обычно сохраняется.

Для 2018 и 2024 требуется .NET Framework 4.8, для 2025 — .NET 8. AutoCAD LT не поддерживается. Совместимость с 2019–2023 не заявляется.

## Лицензия

Компьютер проверяет подписанный статус раз в сутки. Успешная проверка позволяет работать без Интернета до 30 дней; ограниченная лицензия действует не позже назначенной даты. Ошибка связи не продлевает этот срок. После получения подписанного отзыва доступ прекращается. Бессрочность не отменяет периодическую проверку.

Администратор выбирает сотрудника, сохраняет изменения и нажимает «Обновить на GitHub». Подписанные статусы размещаются в папке status. Аварийная лицензия на 30 дней передаётся отдельно и работает без проверки GitHub; импортируется кнопкой «Выбрать лицензию» установщика.

## Обновление и удаление

Панель E-VIP предлагает установить новые версии. Перед обновлением сохраните чертежи и закройте AutoCAD. Для удаления нажмите «Удалить E-VIP» в установщике; при необходимости удалите также лицензию, настройки и кэш.

## Проверки и содержимое

Проверены подписи и скачивание всех 60 пакетов и установщика, автоматические сценарии лицензирования, установки, удаления и повторной установки. Панель предыдущей версии проверена в AutoCAD 2024. Фактическая работа обновлённых команд в AutoCAD 2018 и 2025 и на рабочих чертежах требует испытаний.

Здесь размещаются готовые пакеты и подписанные данные. LISP распространяется в скомпилированном виде FAS. Исходные тексты программ, закрытые ключи, ключ доступа GitHub и личные лицензии сотрудников не публикуются. Открытый доступ к файлам не означает выдачу лицензии на использование программ.
