# E-VIP


Установочные пакеты и обновления инструментов AutoCAD.


Доступен [предварительный выпуск 0.6.0](https://github.com/evipevipevip-cmyk/E-VIP-Releases/releases/tag/v0.6.0-r1) для испытаний. Для работы нужна личная лицензия администратора. Проверка всех функций на чертежах и испытание AutoCAD 2025 ещё не завершены.


## Установка


Получите у администратора установщик E-VIP и файл license.evip. Лицензия передаётся лично и не размещается в этом репозитории. Установщик проверяет подпись каталога и целостность загружаемых пакетов.


Сборки готовятся отдельно для AutoCAD 2024 и 2025. Совместимость с AutoCAD 2018–2023 пока не подтверждена.


## Обновление и удаление


Панель E-VIP проверяет обновления и предлагает открыть установщик. Перед установкой сохраните чертежи и закройте AutoCAD. Для удаления используйте кнопку «Удалить E-VIP» в установщике; при необходимости можно удалить также лицензию, настройки и кэш.


## Содержимое репозитория


Здесь размещаются только готовые пакеты и служебные данные обновлений. Исходники программ, закрытые ключи издателя и личные лицензии сотрудников не публикуются. Наличие файлов в открытом доступе не означает выдачу лицензии на использование программ.
