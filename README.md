# E-VIP

Установочные пакеты и обновления инструментов AutoCAD.

Доступен [предварительный выпуск 0.7.0](https://github.com/evipevipevip-cmyk/E-VIP-Releases/releases/tag/v0.7.0-r3) для испытаний: 60 пакетов, отдельные сборки для AutoCAD 2018 x64, 2024 и 2025, знакомые значки команд и русские сообщения.

## Установка

Получите у администратора архив с установщиком E-VIP и файлом license.evip. Распакуйте архив целиком, закройте AutoCAD и запустите E-VIP_Install.exe. Выберите вашу версию AutoCAD. Установщик проверяет подпись каталога и целостность пакетов, затем скачивает выбранные программы. Личные лицензии передаются отдельно и здесь не публикуются.

Для 2018 и 2024 требуется .NET Framework 4.8, для 2025 — .NET 8. AutoCAD LT не поддерживается. Совместимость с 2019–2023 не заявляется.

Проверены автоматические сценарии установки, удаления и повторной установки всех пакетов; панель загружена в AutoCAD 2024. Фактическая загрузка панели и работа команд в AutoCAD 2018 и 2025, а также все функции на рабочих чертежах ещё требуют проверки.

## Обновление и удаление

Панель E-VIP проверяет обновления и предлагает открыть установщик. Перед обновлением сохраните чертежи и закройте AutoCAD. Для выбора AutoCAD 2018 используйте установщик версии 0.7.0 или новее.

Для удаления нажмите «Удалить E-VIP» в установщике; при необходимости можно удалить также лицензию, настройки и кэш.

## Содержимое репозитория

Здесь размещаются готовые пакеты и подписанные данные обновлений. LISP распространяется в скомпилированном виде FAS. Исходные тексты программ, закрытые ключи издателя и личные лицензии сотрудников не публикуются. Наличие файлов в открытом доступе не означает выдачу лицензии на использование программ.
