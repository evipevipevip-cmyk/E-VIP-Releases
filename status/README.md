# Подписанные статусы лицензий E-VIP

В этой папке администратор размещает файлы вида `<технический-ID>.signed`. Начиная с E-VIP 0.8 их создаёт кнопка «Обновить на GitHub» в программе администратора после разовой настройки доступа.

Компьютер сотрудника проверяет цифровую подпись своего статуса и применяет опубликованные условия. Для новой схемы бессрочного доступа, изменения сроков и остановки требуется обновление клиента до E-VIP 0.8.

Имена сотрудников, файлы license.evip, закрытый ключ подписи, ключ доступа GitHub и исходники программ в этой папке не размещаются. Аварийная офлайн-лицензия на 30 дней передаётся сотруднику отдельно.
